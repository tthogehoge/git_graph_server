# git_graph_server

git のコミットグラフを、見やすいように大胆に省略してブラウザで表示するローカルサーバーです。
ログやコミットの詳細、ファイルの差分は、クリックしたときに git から取得します。

## 必要なもの

- Python 3（標準ライブラリのみ）
- git
- [Graphviz](https://graphviz.org/)（`dot` コマンド）

## 使い方

リポジトリのディレクトリで実行します。

```
python git_graph_server.py --open
```

`http://127.0.0.1:8000/` が開きます。別のリポジトリを指定する場合は `-C` を使います。

```
python git_graph_server.py -C /path/to/repo --port 8080
```

終了は `Ctrl+C` です。

## 画面の見方

グラフには次のコミットだけを残します。

- ブランチ、リモートブランチ、タグ、HEAD が指すコミット
- 末端のコミット
- 上記どうしの最初の共通祖先（merge-base）

それ以外は省略し、省略した個数をエッジのラベル（`+N`）で表示します。
向きは下から上で、古いコミットが下にあります。

| 操作 | 結果 |
| --- | --- |
| ノードをクリック | そのコミットから最初までの `git log --oneline` を全件表示（末尾までスクロールすると続きを読み込み） |
| エッジをクリック | 省略された区間の `git log 親..子` を表示 |
| ログの行をクリック | コミット詳細（作者、日時、メッセージ全文、変更ファイル一覧）を表示。「← 履歴一覧に戻る」で一覧に戻る |
| 変更ファイルをクリック | 新しいタブで差分ページを開く（左側に同じコミットの変更ファイル一覧） |
| Ctrl（Mac は ⌘）+クリックでコミットを2つ選ぶ（グラフのノードでもログの行でもよい） | 2つのコミット間の変更ファイル一覧を表示。最初に選んだ方が A（青）、次が B（橙）で、A → B の差分になる。選んだコミットはグラフのノードとログの行の両方にハイライトされる。「A ⇄ B 入れ替え」で向きを逆にでき、ファイルをクリックすると新しいタブで差分を開く |

直前に通常クリックしたノード（またはログの行）があれば、それが A になり、別のノードやログの行を Ctrl+クリックするだけで A → B の比較になります。ノードとログの行は組み合わせても構いません（グラフで A を選び、ログの行を B にするなど）。比較結果から「← 履歴一覧に戻る」でログに戻って、別の行を選び直せます。3つ目を Ctrl+クリックすると古い方が外れ、通常クリックすると比較の選択は解除されます。

ログの各行のハッシュ、コミット詳細、比較画面（A / B）、差分ページには「コピー」リンクがあり、クリックすると40桁のフルハッシュをクリップボードにコピーします（行の選択や比較の選択には影響しません）。`localhost` 以外の http（`--host 0.0.0.0` で LAN から開いた場合など）では、ブラウザの制限で Clipboard API が使えないため、代替の方法でコピーします。

グラフの作成には時間がかかることがあるため、ページを開いた直後は「読み込み中」画面（経過秒数つき）を表示し、完成したらグラフに切り替わります。ブラウザをリロードすると、ブランチやタグ、HEAD の変化に追従して最新の状態に更新されます（変化がなければキャッシュを使うので速く開きます）。
ページを開いたままでも、グラフの右上の「↻ 更新」ボタンで最新の状態に更新できます（ほかのターミナルで変更やコミットをしたあとなど）。

## 未コミットの変更（WIP ノード）

作業ツリーに未コミットの変更があると、HEAD のコミットの上に破線の **WIP** ノード（「N 件の変更」つき）が出ます。変更がなければ出ません。

- WIP ノードをクリックすると、変更ファイルの一覧を **競合 / ステージ済み / 未ステージ / 未追跡** に分けて表示します。ファイルには変更の種類（M 変更、A 追加、D 削除、R リネーム、? 未追跡）のバッジと、追加・削除行数が付きます。
- ファイルをクリックすると、新しいタブで差分を開きます。ステージ済みは `git diff --cached`、未ステージは `git diff`、未追跡は `/dev/null` との差分です。同じファイルがステージ済みと未ステージの両方にある場合は、別々に表示します。
- パネルの「↻ 更新」で、変更ファイルの一覧とグラフを取り直します。
- WIP ノードは比較（Ctrl+クリック）の対象にはなりません。
- `--no-wip` で WIP の表示を無効にできます。bare リポジトリ（ワークツリーなし）では自動的に無効になります。
- 未追跡ファイルの差分では、いま未追跡と報告されているファイルだけを読みます（任意のパスは読めません）。シンボリックリンクは、リンク先の内容ではなくリンク先のパスを表示します。

## ブランチ・タグ・チェックアウト

コミット詳細（ログの行をクリックして開く画面）に操作パネルが出ます。

- **ブランチ作成**: ブランチ名を入れて作成します。「作成後にチェックアウト」にチェックすると、作成と同時に切り替えます。
- **タグ作成**: タグ名を入れて作成します。メッセージも入れると注釈付きタグになります。
- **チェックアウト**: そのコミットを detached HEAD でチェックアウトします。そのコミットにローカルブランチが付いている場合は、`checkout <ブランチ名>` のボタンも出ます。

チェックアウトは確認ダイアログを出してから実行します。作業ツリーに衝突する変更があるときは git がエラーにするので、そのメッセージをそのまま表示します（強制的な切り替えはしません）。
実行すると、グラフは表示したまま自動で更新され、新しいブランチ・タグや HEAD の位置が反映されます。

この機能はリポジトリを書き換えるため、次の制限があります。

- 既定では `127.0.0.1` で待ち受けているときだけ有効です。`--host 0.0.0.0` などでは無効になり、`--allow-write` を付けたときだけ有効になります。
- `--read-only` を付けると、常に無効（操作パネルが出ない）になります。
- 他のサイトのページから勝手に実行されないように、JSON 以外のリクエストや、Origin / Host が一致しないリクエストは拒否します。

## オプション

| オプション | 説明 |
| --- | --- |
| `revs...` | 対象にする rev（例: `main dev`）。省略時は `--all` |
| `-C PATH` | リポジトリのパス（既定: カレントディレクトリ） |
| `--host HOST` | 待ち受けアドレス（既定: `127.0.0.1`） |
| `--port PORT` | ポート番号（既定: `8000`） |
| `--open` | 起動後にブラウザで開く |
| `--no-remotes` | リモートブランチを除外 |
| `--no-tags` | タグを除外 |
| `--no-count` | 省略数（`+N`）の計算をしない |
| `--rankdir DIR` | グラフの向き。`BT`（下から上、既定）/ `TB` / `LR` |
| `--no-wip` | 未コミットの変更（WIP ノード）を表示しない |
| `--read-only` | ブランチ作成・タグ作成・チェックアウトを無効にする |
| `--allow-write` | `127.0.0.1` 以外で待ち受けるときも、書き込み操作を許可する |
| `--dot` | Graphviz の dot を標準出力に出して終了（サーバーは起動しない） |

## 注意

- 既定では自分のマシンからだけアクセスできます。`--host 0.0.0.0` にすると、同じネットワークの他の人にも履歴が見えます（書き込み操作は `--allow-write` を付けない限り無効のままです）。
- 残すコミットの組み合わせごとに merge-base を調べるので、ブランチやタグが数百あると起動やリロードが遅くなります。その場合は `--no-tags` や `--no-remotes`、rev の指定で減らしてください。
